## Oracle 2026.9.0

This release adopts [year.month.patch versioning](../VERSIONING.md).

Changes since the published 0.2.6 release:

- Codex connects through Astrid's persistent MCP gateway; Claude and Grok use
  the AOS-owned MCP serve path. Workspace context is kept separate from the
  product runtime directory.
- Host adapters verify the selected AOS installation and canonical runtime
  executable before launch, restore stopped runtime state before metadata
  queries, and preserve each host's principal identity.
- Installation preserves existing pack state on failure and rejects invalid
  host markers, conflicting principals, and redirected installation paths.
- Host hooks deliver response/session events to their originating sessions.
- Linux musl installations select native musl runtime targets.
- The 12-asset release contains host packs and plugins, not a second copy of
  the MCP capsule. Each host requires AOS-provided `aos-mcp` and `aos-skills`,
  plus `aos-forge` when available; other Distro capsules are not blanket-granted.

Requires signed AOS 2026.9.0 or newer with the executable metadata and capsule
inventory expected by these adapters. First use may require host consent.
Rehearsal trust identities do not replace production signature verification.
