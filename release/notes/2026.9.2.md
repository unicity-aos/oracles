## Oracle 2026.9.2

Changes since the published 2026.9.1 release:

### Fixed

- Refresh previously managed host capsules through the authenticated AOS
  distribution during an Oracle upgrade, while preserving the host principal
  and its durable data. Unknown same-name capsule bytes still fail closed.
- Keep generated Codex setup and dynamically discovered AOS capabilities usable
  without requiring a Codex restart or a hard-coded tool catalog.
- Include the AOS-owned hook adapter in each host's required capsule set so hook
  events do not incur avoidable timeout waits.
- Treat the Astrid runtime contract as a minimum version while continuing to
  authenticate the actual runtime identity and executable hashes through the
  signed AOS release inventory.

### Changed

- Update the UUID dependency and CI runner hardening.

Requires signed AOS 2026.9.1 or newer and Astrid 2026.9.1 or newer. The
twelve-asset host adapter inventory is unchanged. Oracle does not republish
AOS-owned capsules.
