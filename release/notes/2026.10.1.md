## Oracle 2026.10.1

Changes since the published 2026.10.0 release:

### Fixed

- Start Codex MCP on GNU Linux and MUSL hosts without a global `b3sum`.
  Use the installed AOS checksum implementation after checking its canonical
  executable against the release inventory. Preserve SHA-256 and BLAKE3
  verification of the selected executable, including the final launch check.

The host adapter inventory and runtime compatibility minimum are unchanged.
Start a new client session to activate the installed plugin generation.
