## Oracle 2026.10.2

Changes since the published 2026.10.1 release:

### Fixed

- Continue capsule provisioning when an RC runtime prints an advisory update
  notice containing `astrid update --channel dev`. The installer and packaged
  Claude, Codex and Grok launcher/doctor checks recognize the channel-qualified
  notice while keeping unknown diagnostics and transport failures fatal.
  This fixes the reported Codewall integration installation abort on an
  existing RC installation with a missing host capsule.

The host adapter inventory and runtime compatibility minimum are unchanged.
Start a new client session to activate the installed plugin generation.
