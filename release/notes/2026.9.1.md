## Oracle 2026.9.1

Changes since the published 2026.9.0 release:

Requires signed AOS 2026.9.1 or newer, with the Astrid 2026.9.1 runtime fixes.

### Fixed

- Codex, Claude, and Grok MCP connections answer initialization immediately
  while first-use provisioning continues. `aos_setup_status` reports starting,
  ready, or failed; runtime tools become available on the same connection once
  setup succeeds. A failed installation is not reported as ready.
- Session-start setup hooks return promptly rather than holding host startup
  through installation. Direct diagnostic commands retain their normal checks.
- Recheck daemon readiness after installation retires its setup runtime, so
  first-use launch does not stall on stale startup state.
- Recognize the packaged runtime's missing-capsule diagnostic without treating
  transport or malformed-metadata failures as an absent capsule.

The signed installer, executable verification, and per-host capsule grants
remain in use. Codex, Claude, and Grok retain their selected capsule sets; this
does not grant the whole Community distribution to each host.

First provisioning can still take several minutes. This patch keeps the MCP
connection responsive; it does not claim faster installation. The 12-asset
host-pack/plugin inventory is unchanged. Existing releases are not replaced.
